# Taste
- Wants visually warm, premium, high-craft UI — explicitly rejects "dull", cold, default-looking, or "rubbish" interfaces. Warmth (warm palettes, soft backgrounds, refined typography) is a core requirement, not a nice-to-have. Confidence: 0.7
- Treats a dull/plain appearance as a defect to be fixed alongside functional bugs, not a separate cosmetic concern. Confidence: 0.6
- Prefers real photography (e.g. free stock sources like Pexels) over abstract/illustrative SVG or generated graphics for hero and marketing imagery; dismisses abstract filler visuals as meaningless. Confidence: 0.6
- Wants broad, varied content coverage across categories rather than a single narrow theme (e.g. a catalog spanning many sports, not just one). Confidence: 0.5
- Comfortable with (and asks for) bold, comprehensive overhauls of an entire UI rather than incremental tweaks when the result feels wrong. Confidence: 0.5
- Gives brief, emphatic, informal instructions with typos; expects the agent to interpret intent and infer the full scope of work rather than ask for step-by-step clarification. Confidence: 0.5
- When requesting a novel effect/component, points to an external reference spec (e.g. React Bits component docs) and expects a faithful reproduction of that spec's behaviour and prop surface, not a loose approximation. Confidence: 0.55
